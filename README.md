# react-native-instagram-story

React Native Instagram Story library with native Fabric 3D cube transition

## Installation


```sh
npm install react-native-instagram-story
```


## Usage


```js
import { InstagramStoryView } from "react-native-instagram-story";

// ...

<InstagramStoryView color="tomato" />
```
